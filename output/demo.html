⚙️ 工作流程

# 1. 初始化本地状态（强制入口） python forge/state.py init --state .img2threejs/state.json \ --reference fan.png --profile generic # 2. 探测图像元数据 + 分析 python forge/stage1_intake/probe_image.py fan.png # → agent 视觉分析（分层观察协议） # 3. 预评估 + 细节清单 python forge/stage2_spec/new_pre_spec_assessment.py "ObjectName" \ --image fan.png --complexity moderate --out assessment.json python forge/stage1_intake/build_detail_inventory.py fan.png \ --mode grid-3x3 --out-dir evidence/ --out di.json # 4. 撰写雕刻规格 (sculpt spec JSON) # → 组件层级 / 材质PBR / 几何策略 / 质量契约 python forge/stage2_spec/new_sculpt_spec.py "Name" \ --image fan.png --assessment assessment.json --out spec.json # 5. 验证规格 → 分 pass 构建代码 → 渲染验证 python forge/stage2_spec/validate_sculpt_spec.py spec.json python forge/stage3_build/generate_threejs_factory.py spec.json \ --out src/createModel.ts # 6. 浏览器渲染 → 截图对比 → Divine Eye 诊断 → 迭代修正

✨ 核心能力

🔧

零依赖核心

forge/ 流水线纯 Python 标准库，无需 pip install，无需 GPU。

📐

分阶段构建

Blockout → Structure → Form → Material → Lighting → Interaction，每 pass 有质量门控。

🔄

有界修正循环

Divine Eye 确定性诊断 + VLM 救援层，每 pass 最多 3 次修正，全局上限 6 次。

🤖

Agent 无关

Claude Code / Codex / OpenCode / WorkBuddy 均可运行，统一状态机驱动管线。

🎨

PBR 材质系统

从参考图提取 albedo/roughness/metalness/clearcoat，支持投影纹理路径。

📦

动作就绪

输出含 pivots/sockets/colliders/destruction groups 的运行时层级。
